# Memento (Хранитель)

**Область:** Behavioral / GoF

---

## Смысл паттерна

**Memento** сохраняет **снимок внутреннего состояния** объекта так, чтобы потом восстановить его, **не ломая инкапсуляцию**. Originator создаёт и читает memento; Caretaker хранит стек снимков, но не должен менять их содержимое.

Три роли:

- **Originator** — знает, как сохранить/восстановить себя;
- **Memento** — непрозрачный снимок (для Caretaker);
- **Caretaker** — архив снимков (undo/redo, checkpoints).

```
Originator.save() → Memento → Caretaker.push()
Originator.restore(memento) ← Caretaker.pop()
```

---

## Как устроено демо

В `memento.js` — **текстовый редактор**:

| Класс | Роль |
|-------|------|
| `Editor` | Originator: `text`, `cursor`, `type()`, `moveCursor()` |
| `EditorMemento` | Снимок `{ text, cursor }`; наружу — только `getState()` для Originator |
| `History` | Caretaker: стек `push` / `pop` |

Сценарий:

1. Печатается `"Hello"` → снимок в историю.
2. `" World"` → второй снимок.
3. `"!"` — без сохранения (текущее состояние изменено).
4. Два `restore(pop())` — пошаговый undo к `"Hello World"`, затем к `"Hello"`.

Caretaker не редактирует memento напрямую — только хранит и отдаёт Originator'у.

---

## Когда применять

- **Undo/redo**, история правок, snapshots в редакторах и играх.
- Нужно откатить состояние **без экспорта всех полей** наружу.
- Checkpoints перед рискованной операцией (транзакционный откат).

**Не стоит**, если достаточно **immutable state + past/future stacks** (Redux, Immer) — идея та же, реализация проще. Для больших объектов memento может быть тяжёлым — тогда delta-snapshots или event sourcing.

---

## Связь с другими паттернами

| Паттерн | Отличие |
|---------|---------|
| **Command** | Хранит *операцию* с undo через inverse; Memento — *снимок состояния* |
| **Prototype** | Клон целиком; Memento — контролируемый снимок с ограниченным доступом |
| **State** | Меняет *поведение* через смену state-объекта; Memento — *восстановление* данных |
| **Immutable snapshots** | Функциональный аналог в современных UI-стеках |

---

## Краткий итог

Memento = **сохранить и восстановить состояние**, не раскрывая внутренности Originator Caretaker'у. В демо редактор пишет текст, History копит снимки после ключевых шагов, `restore` откатывает `text` и `cursor` назад.
