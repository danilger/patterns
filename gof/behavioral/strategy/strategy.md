# Strategy (Стратегия)

**Область:** Behavioral / GoF

---

## Смысл паттерна

**Strategy** выносит **семейство взаимозаменяемых алгоритмов** в отдельные классы с общим интерфейсом. **Context** делегирует работу текущей стратегии и может **сменить её в runtime** без изменения клиентского кода.

Отличие от простой функции-колбэка — явная иерархия стратегий, единый контракт и возможность композиции (decorator strategies, default + override).

```
Context.sort(data) → strategy.sort(data)
Context.setStrategy(new …)  // смена алгоритма
```

---

## Как устроено демо

В `strategy.js` — **сортировка массива чисел**:

| Strategy | Алгоритм |
|----------|----------|
| `BubbleSort` | Ручная пузырьковая сортировка |
| `BuiltInSort` | `[...data].sort((a,b) => a - b)` |
| `ReverseSort` | Встроенная sort по убыванию |

`Sorter` (Context) принимает стратегию в конструкторе, `setStrategy()` меняет её, `sort(data)` делегирует.

Демо на `[5, 2, 9, 1, 7]`:

1. Bubble → `[1, 2, 5, 7, 9]`
2. BuiltIn → тот же порядок
3. Reverse → `[9, 7, 5, 2, 1]`

Один Context, три алгоритма — переключение без правки вызывающего кода.

---

## Когда применять

- Несколько **вариантов одной операции** (сортировка, сжатие, расчёт цены, routing).
- Алгоритм нужно **менять в runtime** (настройки пользователя, A/B, feature flag).
- Хочется **изолировать** тяжёлую или тестируемую логику от Context.
- Условные `if (mode === 'x')` разрастаются — стратегия заменяет их полиморфизмом.

**Не стоит**, если алгоритм один и не будет меняться — inline-функция или один метод проще.

---

## Связь с другими паттернами

| Паттерн | Отличие |
|---------|---------|
| **State** | Состояние *управляет допустимыми переходами*; Strategy — *выбор алгоритма* без FSM |
| **Command** | Объект *действия* с undo; Strategy — *алгоритм* без истории |
| **Template Method** | Скелет в базовом классе, шаги в подклассах; Strategy — *композиция* с делегированием |
| **Dependency Injection** | Strategy часто внедряют через DI-контейнер |

---

## Краткий итог

Strategy = **вынести алгоритм в подставляемый объект**. Context не знает деталей сортировки — только вызывает `strategy.sort()`. В демо `Sorter` переключается между bubble, builtin и reverse на одних и тех же данных.
